# Third-party notices

## virtio-win (VirtIO drivers ISO)

`media/virtio/virtio-win-0.1.285_slim.iso` is a slim build of the
**virtio-win** guest drivers / tools ISO published by the Fedora project
(Red Hat). It is included so Hatchery operators can demo Library Media
bindings (VirtIO target) without downloading a multi-hundred-MB full ISO.

- Upstream downloads: https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/

  and use under the upstream project's terms.
